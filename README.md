An end-to-end Machine Learning pipeline for automated **seismic first-break arrival picking** across multi-site exploration surveys. This project formulates 1D time-series arrival picking as a **2D image segmentation task**, training a deep convolutional **2D U-Net** to map raw seismic gather matrices into binary arrival masks.

---

## 📌 Project Overview

In seismic exploration, geophones record acoustic reflection waves generated by surface energy sources. The **first break** is the exact millisecond timestamp when the primary direct P-wave reaches each receiver geophone.

* **The Problem:** Manual arrival picking across millions of trace channels in modern 3D/4D surveys is computationally slow, labor-intensive, and prone to human operator bias. Traditional signal processing algorithms (e.g., STA/LTA) frequently fail under low Signal-to-Noise Ratios (SNR) and high amplitude attenuation at far offsets.
* **The ML Solution:** By treating a 2D shot gather as a grayscale image (Time vs. Space), a **2D U-Net** leverages both cross-trace spatial continuity and temporal waveform features to accurately delineate the wavefront boundary.

## 📁 Repository Structure & Dual-Notebook Rationale

This repository contains **two distinct Jupyter Notebooks** reflecting different stages of model deployment and experiment tracking:

| File Name | Description & Usage |
| --- | --- |
| **`First-Break picking (Just_Epochs_No_Outputs).ipynb`** | **Primary Evaluation Pipeline:** Trains the baseline 2D U-Net over 20 fixed epochs using combined multi-site training data (Brunswick, Lalor, Sudbury) and evaluates cross-domain deployment on an unseen holdout site (Halfmile). |
| **`First-Break picking (Using_Optuna).ipynb`** | **Automated Hyperparameter Optimization Framework:** Implements an automated tuning pipeline powered by [Optuna](https://optuna.org/). ### 💡 Why Are There Two Separate Notebooks?

Due to local computational hardware constraints during development, hyperparameter search trials (`n_trials`) and epoch limits were conservatively capped in the Optuna notebook to prevent runtime timeouts.

1. **`Just_Epochs` Notebook:** Demonstrates full convergence, complete visualization plots, and downstream time-pick metrics (MAE in ms) over a standard 20-epoch training run.
2. **`Using_Optuna` Notebook:** Serves as a **highly scalable optimization framework**. With high-performance GPU resources, expanding Optuna's trial budget offers a clear path toward further minimizing picking error (MAE).

## 🏗️ Technical Workflow & Pipeline Architecture

```
                                  [ RAW SEISMIC DATASET ]
                             (Brunswick, Lalor, Sudbury, Halfmile)
                                              │
                                              ▼
                                 [ HDF5 Data Parsing ]
                          (Extract Amplitude Matrices & SPARE1)
                                              │
                                              ▼
                             [ Preprocessing & Slicing ]
                    • Z-Score Amplitude Normalization (μ=0, σ=1)
                    • Time Axis Resizing (Height = 768)
                    • Horizontal Patch Slicing (Width = 256)
                                              │
                                              ▼
                                [ 2D U-Net Architecture ]
                                              │
                                              ▼
                           [ Predicted 2D Probability Mask ]
                                              │
                                              ▼
                              [ Post-Processing Conversion ]
                       (Extract row index where P >= 0.5 ➔ Time ms)

```

### 1. Data Processing & Patch Slicing

* **Input Dimensions:** Shot gathers vary in width across receiver arrays. Gathers are sliced into uniform image patches of shape **$768 \times 256 \times 1$**.
* **Dimension Rationales:**
* **Height ($768$):** Preserves native temporal sample resolution (~751 samples) without compression loss.
* **Width ($256$):** Standardizes variable geophone receiver trace counts while preventing GPU Out-Of-Memory (OOM) errors.
* **Divisibility:** Both dimensions ($768$ and $256$) are cleanly divisible by $2^3 = 8$, matching the 3 Max-Pooling stages of the U-Net downsampling path.



### 2. Traditional Benchmark (STA/LTA)

Before training deep learning models, a classical **Short-Term Average / Long-Term Average (STA/LTA)** energy ratio algorithm was implemented on baseline shot gathers to establish a quantitative Mean Absolute Error (MAE) benchmark in milliseconds.

## 📐 2D U-Net Network Architecture

The network utilizes a symmetric encoder-decoder structure with skip connections to preserve fine spatial arrival boundaries:

```
          Input Patch (768 x 256 x 1)
                     │
 [Conv 3x3, 16] ───► █ ═════════════════════════════► █ [UpConv + Concatenate]
                     │ (Skip Connection)             │
                [MaxPool 2x2]                    [UpSample 2x2]
                     │                               │
 [Conv 3x3, 32] ───► █ ═══════════════════════► █ [UpConv + Concatenate]
                     │ (Skip Connection)       │
                [MaxPool 2x2]              [UpSample 2x2]
                     │                         │
 [Conv 3x3, 64] ───► █ ═════════════════► █ [UpConv + Concatenate]
                     │ (Skip Connection) │
                [MaxPool 2x2]        [UpSample 2x2]
                     │                   │
                     └───► [Bottleneck] ─┘
                       (Conv 3x3, 128)
                               │
                               ▼
                    Output Mask (768 x 256 x 1)
                     (Sigmoid Activation)

```

## 📊 Performance Metrics

Model evaluation is split between **computer vision segmentation accuracy** and **domain-specific geophysical timing accuracy**:

| Metric Category | Metric Name | Description / Formula |
| --- | --- | --- |
| **Segmentation (Pixel-Level)** | **Mean IoU (Jaccard Index)** | Measures spatial overlap between predicted binary mask ($\hat{Y}$) and true mask ($Y$). |
| **Segmentation (Pixel-Level)** | **Binary Cross-Entropy Loss** | Quantifies pixel-wise probability error during training. |
| **Geophysical (Domain-Level)** | **Mean Absolute Error (MAE)** | Average time deviation in milliseconds between true human pick ($t_{\text{true}}$) and predicted pick ($t_{\text{pred}}$): <br>$$\text{MAE} = \frac{1}{N} \sum_{i=1}^{N} \left\vert{} t_{\text{true}, i} - t_{\text{pred}, i} \right\vert{}$$

 |

## 🌍 Cross-Domain Generalization (Holdout Deployment)

To evaluate real-world commercial viability, the model was trained on three distinct survey sites (**Brunswick**, **Lalor**, and **Sudbury**) and evaluated on an unseen holdout deployment site (**Halfmile**):

* **Train Set:** Brunswick + Lalor + Sudbury Gathers
* **Validation / Deployment Set:** Halfmile 3D Gather Data

This out-of-domain test proves that the U-Net learns true wavefield physical dynamics and lateral wavefront continuity rather than memorizing site-specific noise signatures.
